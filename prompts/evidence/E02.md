# E02 仮説と検証

## 調査前後の認識を対応させる

- 調査・聞き取り・試行の報告や、企画の再検討に使う。
- 左半分は白地で事前仮説、右半分は濃い主役色の地に白文字で検証結果を示す。
- 左右とも3〜5行とし、同じ項目同士を同じ高さに置く。中央の楕円へ項目名を記して対応をつなぐ。
- 想定と異なった行だけを強調し、その行に次の施策を短く記す。
- 全て異なった場合は、施策への影響が最も大きい一行だけを強調する。
- 全て想定どおりなら強調を設けず、タイトルで確認されたことを言い切り、その次の行動を添える。
- タイトルは施策を最も変える発見を、事実と意味がある1〜2文、二行以内で表す。
- 資料欄に調査対象、人数、実施時期を書く。
- 事前の仮説は当時の認識を保ち、結果を知った後から劣った考えに書き換えない。
- 追加の強調色は使わず、選んだ行だけを太字にする。
- 検査では左右が同じ項目について述べているか、発見または仮説の確認が次の行動につながるかを見る。
- 文章設計にはタイトル、左右の全行、強調箇所と次の施策、資料欄を含める。
- 入力には当初の考え、判明した事実、調査方法を受け取る。
