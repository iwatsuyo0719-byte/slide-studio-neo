# E03 ひと工夫したグラフ

## 読み取る差へ視線を誘導する

- 金額・件数・比率がどう動いたか、何と比べてどうかを、報告や提案で見せたい時に選ぶ。
- 主となるグラフを一つ選ぶ。推移は折れ線か縦棒、項目比較は横棒、内訳の変化は積み上げとする。
- 隣のグラフや内訳へ値を接続する手法を選んだときだけ、二つ目の図を隣接させる。
- 読み取りの工夫は次の候補から一つか二つに絞る。
- 工夫の候補は、差・伸び率を記した丸角の札、注目する系列だけの着色、目標線と未達幅、隣図への引き出し線による数値接続とする。
- グラフの直下または隣に、読み方を一行で記す。
- タイトルに数値を含め、差や変化の事実と意味を1〜2文、二行以内で述べる。
- 資料欄へ数値の出所と基準時点を記す。
- 差と伸び率は入力された値から計算し、計算値である旨を注に書く。
- 棒の目盛は0から始める。
- 主役色は注目すべき部分だけに割り当て、残りは灰色にする。
- 検査では二秒程度で意図した差へ目が向くか、補助表現がタイトルの差を指すか、補助が多すぎて図を読めなくしていないかを見る。
- 成果物より先に、選んだ図の種類と付加した工夫をそれぞれ一行で示す。
- 文章設計にはタイトル、図の形式と値、工夫の座標または位置、注、資料欄を含める。
- 入力には値の表、伝えること、出所、基準時点を受け取る。
